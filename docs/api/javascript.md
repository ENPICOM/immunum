# JavaScript

The TypeScript declarations the npm package ships (`immunum.d.ts`), generated from the bindings
in `src/wasm.rs`. Results are camelCase: `queryStart`, `queryEnd` and `errorKind` are
`query_start`, `query_end` and `error_kind` in the other interfaces. Examples are in the
[JavaScript guide](../usage/javascript.md).
